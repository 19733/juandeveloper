# 🎮 Jornalistas Gamers - Projeto de Conclusão (Novotec)

Este repositório contém o código-fonte do website **Jornalistas Gamers**, desenvolvido como **Projeto de Conclusão de Curso** do Novotec. O site é uma plataforma dedicada a notícias, análises e artigos focados no universo dos jogos eletrônicos.

## ✨ Destaques e Objetivos

* **Foco Principal:** Demonstração de habilidades em **desenvolvimento front-end** e implementação de **design responsivo**.
* **Status Atual:** O último grande commit foi focado em corrigir e otimizar a responsividade do layout para diferentes dispositivos.

## 🛠️ Estrutura do Projeto

A organização do código segue o padrão de projetos web para garantir clareza e manutenção:

| Pasta/Arquivo | Descrição |
| :--- | :--- |
| **`css/`** | Arquivos de **estilo CSS** que controlam a aparência e o layout do site. |
| **`font/`** | Armazena **fontes customizadas** utilizadas no design. |
| **`img/`** | Inclui todas as **imagens**, ícones e assets gráficos do site. |
| **`js/`** | Scripts **JavaScript** para interatividade e funcionalidades front-end. |
| **`index.html`** | A **página inicial** e principal do website. |

### Tecnologias Utilizadas

* **HTML5:** Estrutura semântica do conteúdo.
* **CSS3:** Estilização e implementação do **Design Responsivo**.
* **JavaScript:** Interação e funcionalidades dinâmicas.
